# 谁在水积分 · SWTT 在线大富翁

公网地址：<https://swtt-online.onrender.com>

基于工作区现有棋盘、角色和卡牌素材制作的在线房间版。创建房间后把 4 位房间码发给朋友，即可加入同一局。

## 本地启动

```bash
npm install
npm start
```

打开 <http://localhost:3000>。也可以双击 `启动游戏.bat`。

- 支持 2-8 人，角色不可重复。
- 每站奖杯上限 3 个；过路费按 `原始积分 × 奖杯数 ÷ 场上人数` 计算。
- 卖房按整站 `原始积分 × 奖杯数 ÷ 2` 一次性回收。
- 每个角色有独立角色卡：主场加分、骰子能力、人物羁绊；游戏内点“角色卡”查看。
- 布鲁龟支付其他玩家时，按金额最高位由自己支付，其余零头由雨果龟代付。
- “积分失效”失去当前位置逆时针最近一站的 1 个奖杯。
- 积分可以为 0，但不会变成负数；积分为 0 时不会被强制借款或卖房。
- 只有当前积分不足以支付本次金额时，才优先选择借积分，或自己选择卖出哪座奖杯凑够本次支付；否则接受淘汰。借款和卖奖杯选择都提供“退出选择”，可返回上一步，避免误点。
- 人物特性的加分（主场、羁绊、蛰伏等）先于本次扣分计算。
- 借积分、卖房等主动积分变动后，若仍在可购买地块，会重新判断能否购入当地奖杯。
- 所有再次掷骰（卡牌、成都/伦敦、乒超、拼刺刀、双打等）均由对应玩家手动点击。
- 重新掷骰、选择前进步数或发动神的旨意时，可先点“查看地图”收起弹窗，再用“继续掷骰/继续选择”恢复。
- 雨果龟到达健身房获得双倍积分（+1000）。
- 成都混团世界杯、伦敦世乒赛团体不可购入奖杯；到达后手动掷骰获得点数×100，米其林在此正常 +20。
- 金奈只在到达时触发第一次 -100、第二次 -50；路过不扣分。
- 所有道具卡可点击查看大图；只有轮到自己时才能点击“使用”，由服务器判定当前是否可用。
- 持有嫁祸/顿悟/翻身到达他人地产时会自动询问是否使用；选择不使用、或嫁祸后改选自己支付，卡牌都会保留。
- 持有请神到达自己地产时会自动询问是否使用；只有该地在本次回合开始前已持有奖杯时才能触发或手动使用。
- 结算分为积分榜和奖牌榜：积分榜只看现有积分，奖牌榜按奖杯数量排序并列出奖杯名称；结算大字同时显示两个榜单第一。
- 其他玩家会同步看到当前玩家抽到的命运/机会卡；抽卡者关闭后同步隐藏。
- 开屏选择角色时，点击角色头像可先查看角色卡，再选择“选定”或“返回”。
- 所有角色头像与棋子使用 `qizi/` 中的新立绘。
- 结算大字分两行显示“🎉积分世一xxx🎉 / 🏆奖杯榜一xxx🏆”。
- 房间状态保存在服务器内存中；服务器重启后房间会消失。
- 规则手册、机会/命运卡、赞助道具卡均使用工作区原图，并在游戏内按原效果结算。

## 免费发布到 Render

仓库已包含 `render.yaml`：

1. 把本目录上传到 GitHub 仓库。
2. 在 Render 新建 Blueprint，选择该仓库。
3. 使用 Free 实例部署，启动命令为 `npm start`。

Render 免费实例当前提供每月 750 小时、免费 `onrender.com` 子域名，支持 WebSocket。免费实例在 15 分钟无 HTTP/WebSocket 消息后会休眠，下一次访问需要约 1 分钟唤醒；休眠或重启会清空内存中的房间。免费额度按月重置，服务本身没有固定到期日，但免费政策和配额可能由平台调整，且没有 SLA。

如果需要长期 24 小时在线，可改用 Oracle Cloud Always Free 虚拟机，或把房间状态迁移到持久化数据库后部署到其他平台。
